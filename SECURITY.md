# Security

ProofPay is unaudited hackathon software. Do not use it to hold funds or expose private wallet material.

- Never submit a seed phrase, private key, password, or wallet backup.
- Verify chain IDs and token contract addresses from official sources.
- Test the optional anchor flow only on Arbitrum Sepolia with faucet assets.
- Treat receipt exports as public-chain evidence, not proof of an off-chain legal agreement.

No production security guarantee is made.
